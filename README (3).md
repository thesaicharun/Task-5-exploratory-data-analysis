# Task 5 - Exploratory Data Analysis (EDA)

## Data Analyst Internship

This project performs Exploratory Data Analysis on the Titanic dataset
using Python.

## Objective

The objective of this task is to extract insights using statistical
and visual exploration.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

Titanic Dataset

## Analysis Performed

The following analyses were performed:

- Dataset loading
- Dataset structure analysis
- Data types analysis
- Missing value analysis
- Descriptive statistics
- Value counts
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Histograms
- Boxplots
- Scatterplots
- Correlation analysis
- Correlation heatmap
- Pairplot
- Skewness analysis
- Family size analysis

## Key Findings

- Survival differs between passenger groups.
- Gender has a strong relationship with survival.
- Passenger class is associated with survival.
- Fare is right-skewed.
- Boxplots reveal potential outliers.
- Correlation analysis helps identify relationships between numerical variables.
- EDA helps identify patterns, trends and anomalies.

## Files

- `Task_5_EDA.ipynb` - Jupyter Notebook containing the complete analysis.
- `Titanic_Dataset.csv` - Dataset used for analysis.
- `Task_5_EDA_Report.pdf` - PDF report of the analysis.
- `screenshots/` - Screenshots of important outputs.

## Conclusion

The Titanic dataset was explored using statistical methods and
visualizations. EDA helped identify missing values, distributions,
relationships, trends and potential anomalies in the dataset.
